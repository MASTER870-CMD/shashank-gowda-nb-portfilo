Project Overview

During my engagement with the J.P. Morgan Software Engineering Virtual Experience, I was tasked with architecting Midas Core, a backend microservice designed to process high-volume financial transactions in real-time. The system ingests live data, validates user balances in real-time, persists records to an ACID-compliant database, and interfaces with an external incentive API.

Key Achievements

  • Real-Time Messaging: Configured Apache Kafka consumers to ingest financial transaction data asynchronously, ensuring zero latency during high-traffic periods.
  • Data Persistence: Modeled SQL relationships using JPA entities (`UserRecord`, `TransactionRecord`) and integrated an in-memory H2 database for ACID-compliant storage.
  • API Development: Built a REST Controller (`/balance`) to expose user financial data securely to frontend clients, handling validation logic and edge cases.
  • System Reliability: Wrote comprehensive JUnit integration tests to verify transaction flows and balance updates.
